# # Gözcü Görevi – Unity Projesi

## Proje Hakkında
Bu proje, Unity kullanılarak geliştirilen Gözcü Görevi ödev projesidir. Oyunda oyuncu hareketi, kamera kontrolü ve gözcünün görüş sistemi bulunmaktadır.

## Kullanılan Teknolojiler
- Unity
- C#
- Unity Input System
- Git ve GitHub

## Oyuncu Kontrolleri

| Tuş | Görev |
|---|---|
| W, A, S, D | Oyuncuyu hareket ettirir. |
| Shift | Oyuncunun daha hızlı hareket etmesini sağlar. |
| Fare | Oyuncunun bakış yönünü kontrol eder. |
| Space | Oyuncunun zıplamasını sağlar. |

## Gözcü Sistemi
Gözcü, oyuncuyu görüş alanı içerisinde algılamak üzere tasarlanmıştır. Görüş kontrolü, oyuncunun konumu ve görüş hattı dikkate alınarak yapılır.

## Proje Klasörleri
- **Assets:** Oyun sahnesi, C# scriptleri ve kullanılan varlıklar.
- **Packages:** Projede kullanılan Unity paketleri.
- **ProjectSettings:** Projenin Unity ayarları.

## Projeyi Açma
1. Depoyu bilgisayarınıza indirin veya klonlayın.
2. Unity Hub üzerinden projeyi ekleyin.
3. Projeyi uygun Unity sürümüyle açın.
4. `Assets` klasöründeki ana sahneyi açarak oyunu çalıştırın.
